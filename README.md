## 🏆 **Projects**  

A few things I've built or am currently working on:

### [liiku-client](https://github.com/pr0fix/liiku-client) & [liiku-server](https://github.com/pr0fix/liiku-server)
A real‑time transit viewer using React + Vite on the front end and a Node.js WebSocket+REST API server that streams GTFS and live vehicle data onto a MapLibre map.
- **Tech:** React, TypeScript, Vite, MapLibre GL, WebSockets, Node.js, Express, GTFS, HSL API

### [CoffeeCompanion](https://github.com/pr0fix/CoffeeCompanion)
A React Native mobile app for finding nearby cafés based on your location.
- **Tech:** React Native, Expo, Firebase, Foursquare API

### [caffeinated-strings](https://github.com/pr0fix/caffeinated-strings)  
A JavaScript/TypeScript string‑utility library with an automated CI/CD pipeline that handles versioning and publishing to npm.
- **Tech:** JavaScript, TypeScript, ts‑jest, GitHub Actions, npm

More projects and experiments available in my **[repositories](https://github.com/pr0fix?tab=repositories)**
